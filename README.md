## 🤖 Как настроить получение ответов в Telegram (за 1 минуту)

### Шаг 1. Создайте бота в Telegram:
1. Откройте в Telegram официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Задайте имя (например, `Мой Чат Модератор`) и юзернейм (например, `my_stream_quiz_bot`).
4. Скопируйте полученный **HTTP API Token** (выглядит как `7123456789:AAFxX...`).
5. Нажмите `/start` в своем новом боте, чтобы разрешить ему отправлять вам сообщения.

### Шаг 2. Узнайте свой Telegram ID:
1. Откройте бота **[@userinfobot](https://t.me/userinfobot)**.
2. Он напишет ваш цифровой **Id** (например: `123456789`).

### Шаг 3. Подключите к тесту (2 простых способа):

* **Способ А (самый простой):**
  Откройте `index.html` в браузере, нажмите в правом верхнем углу кнопку **`⚙️ Telegram`**, вставьте токен и Chat ID и нажмите кнопку **`🧪 Тест связи`**. Вам тут же придет тестовое уведомление! Настройки сохранятся в браузере.

* **Способ Б (в коде):**
  Откройте файл `config.js` в любом текстовом редакторе и вставьте значения:
  ```javascript
  const TELEGRAM_CONFIG = {
    botToken: 'ВАШ_ТОКЕН_ОТ_BOTFATHER',
    chatId: 'ВАШ_TELEGRAM_ID'
  };
  ```

## 🌐 Как бесплатно разместить тест в интернете (чтобы скидывать ссылку)

1. **GitHub Pages (Бесплатно)**:
   - Создайте репозиторий на github.com и загрузите туда файлы `index.html` и `config.js`.
   - В Settings -> Pages выберите ветку `main` -> Save.
   - Вы получите ссылку вида: `https://ваш-логин.github.io/имя-репозитория/`.
2. Либо просто перетащите папку на бесплатный хостинг **Netlify Drop** (drop.netlify.com) или **Vercel** за 10 секунд без программирования!
